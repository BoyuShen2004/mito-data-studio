# Projects and volumes

A project page is the workspace for data, assignment, access, and activity.
Its tabs are **Overview**, **Data**, **Assign**, **Access**, and **Activity**
when the signed-in role has permission for each area.

## Requester workflow

1. Create a project and register one or more datasets.
2. Review the dataset and volume rows in the project.
3. Wait for a manager to approve the project for assignment.
4. Follow task and review status from the project or requester dashboard.

## Manager workflow

1. Open a project awaiting review and verify its data.
2. Choose **Approve & enable assignment**.
3. Select the working team and project access in the relevant tabs.
4. Open **Assign** to create/update the whole-volume tasks and assignees.

The **Data** tab lists datasets and volumes. A volume page combines source and
streaming metadata with its single task. **View** opens a read-only viewer;
**Annotate** appears for a manager or the assigned annotator when the task is
open for annotation.

The viewer top bar reserves stable slots for task identity, Region only and
Overwrite, Axis, mode switching, Submit, and Share. Controls appear only when
relevant, but their reserved layout prevents nearby controls from jumping.
